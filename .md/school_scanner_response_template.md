# School Scanner MVP Response Template

Use this template for the first MVP version of the School Scanner AI response.

Goal: give parents a fast, tailored decision brief rather than a generic school report.

Principles:
- answer the user's actual question first
- make the shortlist easy to scan
- focus on fit, tradeoffs, and realism
- include both recommendations and fallback thinking
- keep the tone clear, practical, and parent-friendly
- ground factual claims in official or reliable sources where possible
- make it easy for the user to trace claims back to named sources

Evidence rules:
- prefer official school websites, government sources, Ofsted, ISI, and equivalent primary sources
- clearly separate verified facts from interpretation
- if a ranking or comparison is not based on a robust source, say so plainly
- if a data point is unavailable, outdated, or not applicable, state that directly rather than guessing
- treat destination outcomes as evidence-based only when the destination source is explicit
- never infer destination strength from reputation alone

---

## 1. Direct Answer

Start with a short paragraph that directly answers the user's likely intent.

Examples of intent:
- "What are the best schools near this postcode?"
- "Is this specific school a good fit?"
- "How do these two schools compare?"
- "Is this area good for families choosing between state and private schools?"

Template:

> Based on your interest in **[school name / postcode / area]**, the strongest options to focus on are **[school 1]**, **[school 2]**, and **[school 3]**. The best fit depends mainly on **[fit factor]**, **[fit factor]**, and **[fit factor]**. If your priority is **[priority]**, start with **[school / area]**. If your priority is **[different priority]**, **[school / area]** looks stronger.

---

## 2. School Snapshot

Use this when a named school is part of the query.

Include:
- whether it is primary, secondary, sixth form, or all-through
- whether it is co-ed or single-sex
- whether it is state, private, grammar, academy, faith, or other
- whether it is religious or non-religious
- if relevant, how strongly religion seems embedded in school life based on official materials
- short description of the school's overall character

Template:

### School Snapshot: [School Name]
- Phase: [Primary / Secondary / All-through / Other]
- Type: [State / Private / Grammar / Academy / Other]
- Gender: [Co-ed / Boys / Girls]
- Religious character: [None / Faith-based / Faith-informed]
- How religious it appears in practice: [short explanation]
- Overall description: [short summary]

---

## 3. Top Recommendations

Provide a shortlist of 3 to 5 schools.

For each school include:
- school name
- type: state / private
- approximate relevance to the postcode or named search
- one-line fit summary
- why it made the shortlist

Template:

### [School Name]
- Type: [State / Private]
- Why it stands out: [short reason]
- Best for: [child / family profile]
- Possible drawback: [main caution]
- Relevance to your search: [distance / area / compare context]

## 6. Academic Position And Benchmarking

Use this section carefully and only where the source quality is good enough.

Possible elements:
- whether the school is academically selective
- how it performs in relevant public exams for its age group
- how it compares with strong schools in the same category
- where ranking claims come from

Template:

### Academic Position

- **Exam performance summary:** [short summary]
- **Category standing:** [ranking or benchmark summary if reliable]
- **National benchmark context:** [comparison to strong schools in the same age group, if valid]
- **Confidence note:** [how solid or limited the underlying evidence is]

## 11. Destinations

Use this section when destination pathways matter and the evidence is good enough.

Split it by school phase:
- for primary or prep schools: destination secondaries
- for secondary schools: destination universities

Evidence priority:
- school-published destination lists
- official destination disclosures
- UCAS or university-published school-level data where available
- other clearly attributable, named sources

Rules:
- do not invent destination patterns from isolated anecdotes
- if only partial destination data is available, label it as partial
- if Oxford and Cambridge data come from different sources or years, say so clearly
- if a school does not publish destinations, state that the evidence is limited

### A. Primary / Prep To Secondary Destinations

Focus on:
- strongest destination secondaries
- grammar-school outcomes where relevant
- top private-school destinations where relevant
- whether the destination pattern appears broad or concentrated

Template:

### Destinations: Secondary Schools
- **Best-known destination schools:** [schools]
- **Destination pattern:** [for example, grammar-heavy, independent-heavy, mixed, or unclear]
- **Strength of evidence:** [strong / moderate / limited]
- **What this suggests:** [short interpretation]

### B. Secondary To University Destinations

Focus on:
- Oxford and Cambridge where source-backed
- broader top-UK university destinations where source-backed
- whether outcomes are published as placements, offers, or general destination lists
- whether the school appears unusually strong in top-university admissions relative to peers

Suggested university lens:
- Oxbridge
- plus around 10 other top UK universities where reliable source-backed destination data exists

Template:

### Destinations: Universities
- **Oxbridge evidence:** [summary]
- **Other top UK university destinations:** [summary]
- **Published as:** [offers / acceptances / destinations / mixed]
- **Strength of evidence:** [strong / moderate / limited]
- **What this suggests:** [short interpretation]

### C. Optional Oxbridge Data Table

Use only if the source data is structured enough.

Template:

| Year | Oxford Applications | Oxford Offers | Oxford Acceptances | Cambridge Applications | Cambridge Offers | Cambridge Acceptances | Joint Applications | Joint Offers | Joint Acceptances |
|---|---|---|---|---|---|---|---|---|---|
| [Year] | [n] | [n] | [n] | [n] | [n] | [n] | [n] | [n] | [n] |

Optional additions when reliable:
- sixth form size
- acceptance ratio or offer ratio
- average across all available years

Important caveat:
- if years are missing, show them as missing rather than filling gaps

## 13. Tradeoffs And Risks

This section is important for trust and usefulness.

Include realistic cautions such as:
- very strong school but highly selective
- close to home but weaker fit
- excellent reputation but longer commute
- attractive area but limited backup options
- lower-cost route but catchment-sensitive

Template:

### Main Tradeoffs
- **[School / Area]:** [tradeoff]
- **[School / Area]:** [tradeoff]
- **[School / Area]:** [tradeoff]

## 14. Sources

Always end factual responses with a short source list when the answer depends on external school data.

Template:

### Sources
- [Source name]: [what it supports]
- [Source name]: [what it supports]
- [Source name]: [what it supports]

Recommended source labels for destination work:
- School website: destination disclosures
- UCAS: school-level admissions data
- University admissions dataset: school-level applications, offers, or acceptances
- Ofsted / ISI: inspection context

If destination data is incomplete, add:
- **Data gaps:** [short explanation]

## 15. Best Next Moves

End with practical recommendations.

Template:

### Recommended Next Steps
1. Visit **[school]** and **[school]** first to test real fit and atmosphere.
2. Check **[admissions rule / catchment / deadline / fees / scholarship / transport]** before narrowing your shortlist.
3. Keep **[school / route]** as a realistic fallback if **[primary option]** is too selective, expensive, or uncertain.
4. If you are choosing where to live, focus on **[area / radius / corridor]** first.

## 16. Suggested Follow-Up Questions

Offer simple prompts that keep the user moving.

Examples:
- Compare **[school A]** vs **[school B]**
- Show me the best **state-only** options near **[postcode]**
- Show me the best **private-only** options near **[postcode]**
- Which nearby schools are **less high-pressure**
- Which areas within **[X] minutes** have the strongest school mix
- What are the best fallback options if **[school]** is unrealistic

## Optional Response Modes

### A. Named School Mode
Use when the user enters a school name plus postcode.

Focus on:
- the named school
- closest strong alternatives
- whether the named school looks worth prioritising
- admissions and assessment details where relevant
- inspection and official-data-backed summary
- destination outcomes where source-backed

### B. Postcode / Area Mode
Use when the user enters only a postcode.

Focus on:
- strongest schools nearby
- state vs private split
- whether the area is attractive from a school-choice perspective
- destination strength only if it materially helps the area choice

### C. Comparison Mode
Use when the user asks about two or more named schools.

Focus on:
- side-by-side differences
- best-fit child profile
- key tradeoffs
- final recommendation if possible
- source-backed contrasts rather than vague impressions
- destination outcomes only where the evidence is comparable

---

## MVP Tone Guidance

The response should:
- sound helpful, calm, and informed
- avoid brochure language
- avoid pretending certainty where there is uncertainty
- be honest about selectivity, catchment risk, and tradeoffs
- make parents feel guided rather than overloaded

The response should not:
- dump raw stats without interpretation
- rank schools without explaining why
- ignore fit, commute, or admissions realism
- sound like a directory listing
- treat weak third-party rankings as hard truth
- present incomplete destinations data as comprehensive
